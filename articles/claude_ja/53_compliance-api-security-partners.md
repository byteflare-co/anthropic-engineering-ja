# Claude がさらに多くのセキュリティ・コンプライアンスツールと連携できるようになりました

本日、注目すべきセキュリティ・コンプライアンスツールとの 28 件のインテグレーションを発表します。これにより IT・セキュリティチームは、自社のスタックに含まれる他のアプリケーションを統制するのと同じように、Anthropic のプラットフォームとプロダクト群全体にわたって Claude をガバナンスできるようになります。

## 仕組み

これら新しいインテグレーションはすべて Claude Compliance API によって支えられており、エンタープライズのセキュリティ・コンプライアンスチームに対して、次の 2 種類のデータへのプログラマティックなアクセスを提供します。

- **Claude Enterprise の会話コンテンツ** — チャット、アップロードされたファイル、プロジェクトを含みます。これにより管理チームは、他の業務アプリケーションで既に運用しているセキュリティ、モニタリング、DLP のポリシーを、そのまま Claude にも適用できます。
- **Claude Enterprise と Claude Platform の双方にまたがるアクティビティイベント** — ユーザーログイン、管理者アクション、設定変更を含みます。これによりセキュリティチームは、組織全体で Claude がどのように使われているかを統一されたビューで把握できます。

## Claude Compliance API のインテグレーション

インテグレーションは、エンタープライズが依存している各カテゴリにわたる 28 のセキュリティ・コンプライアンスプロバイダーから、現在利用可能です。DLP、SASE、データセキュリティ、SIEM とセキュリティオペレーション、アイデンティティ、eDiscovery、AI セキュリティポスチャー管理、そして AI オブザーバビリティ・テレメトリーインフラストラクチャといった領域をカバーしています。
