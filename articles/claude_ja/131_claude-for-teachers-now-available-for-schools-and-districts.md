# Claude for Teachers が学校・学区向けにも利用可能になりました

7月、私たちは[Claude for Teachers](https://www.anthropic.com/news/claude-for-teachers)を発表しました。これにより、認証を受けた米国の K-12(幼稚園から高校3年生まで)の教育者に、学習科学に基づいた指導スキルや、全50州の学力基準への直接的な連携、それらに対応した高品質なカリキュラムなど、Claude のプレミアム機能への無料アクセスが提供されるようになりました。

本日より、Claude for Teachers は学校・学区向けに無料の Enterprise 提供として利用できるようになります。学校・学区のリーダーは、シングルサインオンやロールベースアクセス制御、ドメイン取得といった[Enterprise 機能](https://support.claude.com/en/articles/16559896)を備えた、単一の K-12 利用規約のもとで一元管理される1つの組織に、教育者やスタッフをまとめて迎え入れられるようになりました。

### 仕組み

学校・学区の管理者が認証を受け、K-12 利用規約と生徒データプライバシー契約に同意し、自組織のメールドメインとシングルサインオンを接続します。そこから:

- **教育者やスタッフは Claude for Teachers に無料でアクセスできます。** これには、指導スキルや学力基準、その基盤となる高品質なカリキュラム、教師がすでに使っている K-12 向けツールとの連携など、K-12 教育者向けの Claude の機能が含まれます。
- **利用上限は個人版 Claude for Teachers アカウントと同じで、費用はかかりません。** 超過分の課金は、管理者がオプトインしない限りデフォルトで無効になっています。
- **学校・学区の管理者がアカウントを管理します。** 対象条件を満たす学校・学区は、ロールベースアクセス制御やシングルサインオンといった一連の[Enterprise 機能](https://support.claude.com/en/articles/16559896)を利用できます。管理者はスタッフの追加・削除、ポリシーの設定、各学校での導入状況の確認を行えます。
- **ドメイン取得を通じて、**すでに自校・自学区のドメインで認証済みの教師は、一元管理されたアカウントに移行されます。
- **利用規約とプライバシー契約は学校・学区が保持します。** Anthropic は学校・学区単位の K-12 利用規約とデータ処理契約を提供するため、組織全体に FERPA に準拠した一貫したコミットメントが適用されます。Claude for Teachers のデータはモデルの学習には使用されず、生徒情報は K-12 データ処理契約によって保護されます。Claude for Teachers における K-12 プライバシーについての詳細は[こちら](https://support.claude.com/en/articles/15926041-claude-for-teachers-your-data-and-our-terms)をご覧ください。

### 新学期に向けた新機能

新学期を迎える教育者向けに、新しく改良されたリソースも追加しています。

- **Learning Commons と共同開発した、2つの新しい指導スキル。**
  - *授業準備*: Claude が今後の授業の重要な場面を計画するのを手伝い、準備万端で自信を持って授業に臨めるようにします。
  - *理解度チェック*: 生徒の思考を可視化し、次に何を教えるべきかがわかる、学力基準に沿った短い理解度チェックを作成します。ローンチ時点では数学に対応しています。
- **既存スキルの改善。** 生徒向け教材のアクセシビリティを向上させ、授業計画スキルに授業準備のステップを組み込みました。
- **[Claude for K-12 Academy](https://academy.claude.com/collections/k-12) を更新。** K-12 の教師、コーチ、学区チーム向けに、コースやガイド、授業での活用方法を含む無料の AI リテラシーコンテンツです。

これは、教師を支援し生徒の学習成果を向上させることに焦点を当てた、Anthropic の教育分野における幅広い取り組みの一環です。[Beneficial Deployments](https://www.anthropic.com/beneficial-deployments) というミッションを通じて、私たちは教師向けに開発を行う開発者コミュニティのために、引き続き[指導スキルを公共財として公開](https://github.com/anthropics/k12-teacher-skills)しています。この秋には、デトロイト公立学校区でも Claude for Teachers の評価を試験的に実施する予定で、教育者と緊密に連携しながら、教育者のウェルビーイングと実践への影響を調査していきます。

## 始め方

米国の K-12 学校・学区のリーダーは、自組織を認証し、本日から[利用を開始](https://claude.com/solutions/teachers#get-verified)できます。対象条件を満たす組織は、2027年6月30日までに申し込むことで、1年間の無料アクセスを受けられます。
