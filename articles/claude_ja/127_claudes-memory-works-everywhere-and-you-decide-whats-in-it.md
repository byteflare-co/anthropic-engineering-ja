# Claude のメモリはあらゆる場所で機能し、その中身はあなたが決められます

本日より、チャットで使っているメモリは Claude Cowork でも同じものになります。これにより、どこで Claude と作業していても、Claude はすでに知っているあなたの情報を起点に動き始めます。Claude が覚えていることはすべてトピックごとに確認でき、いつでも編集・削除できます。Claude は健康や信条といったセンシティブとされる話題をデフォルトではメモリに保存しませんが、そうした話題こそ何度も説明し直すのに疲れているというのであれば、メモリ設定でオンにすることができます。

![](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/6a8cc19ec0d328f3250d2a32_3bc1dbe9.png)

## **Claude Cowork とチャットで共通の一つのメモリ**

Cowork にもメモリが搭載されました。しかもチャットで使っているものと同じメモリなので、説明し直す手間が減り、前回の続きから始めやすくなります。Cowork がクラウド上でタスクを実行する際には、あなたがチャットで話した内容から Claude が覚えていることがそこにあり、その逆も同様です。何ヶ月にもわたる会話の中で積み上げてきた文脈――たとえば第 3 四半期の優先事項やプロジェクトの進捗状況――は、Cowork にタスクを渡した瞬間からそこにあり、Cowork で出てきた内容はチャットにも引き継がれます。

上司向けの近況報告の下書きを Cowork に頼めば、それが誰で、どのような書き方を好むかをすでに把握しています。会議で企画しているカンファレンスのアジェンダをチャットでブレインストーミングすれば、Cowork が予算やロジスティクスの文書を作成する際に、参加人数、開催都市、登壇者を把握しています。チームの指標の定義の仕方をチャットで一度説明すれば、それ以降 Cowork が作成するすべての四半期ビジネスレビュー(QBR)のデッキでその定義が使われ、再説明の必要はありません。

## **チャットしながらリアルタイムに更新されるメモリ**

Claude は、会話が終わった後に要約するのではなく、チャットしている最中にトピックをメモリへ追加するようになりました。プロジェクトの締め切りが 9 月に変わったと伝えれば、「これを覚えておいて」と言わなくても、次の会話ではすでにそれを把握しています。メモリはいつでも一時停止したりリセットしたりできます。

## **保存されたメモリの確認と編集**

Claude が覚えていることはすべて、メモリ設定の「トピック」内のファイル一覧としてまとまっており、それぞれを読んだり、編集したり、削除したりできます。ファイルは短く、一度直せばあらゆる場面に反映されます。たとえば会社の旧社名を 1 つのファイルで修正すれば、それ以降のすべての会話で正しく認識されるようになります。

## **センシティブな話題を Claude に覚えさせるかどうかを決める**

デフォルトでは、Claude は健康状態、人種、民族、宗教的信条、政治的立場、性自認など、個人的あるいはセンシティブとされる話題に関する情報を保存しません。

しかし、ある人にとってセンシティブなことでも、別の人にとっては Claude に覚えておいてほしい有用な情報かもしれません。「メモリにセンシティブな話題を含める」設定をオンにすると、たとえば週の作り置き用レシピを提案する際に、グルテンアレルギーがあることを Claude が覚えて活用してくれるようになります。

この設定をオンにすると、Claude がこれらの話題に関する情報をメモリに保存するたびに通知が表示されます。センシティブな話題が保存されるのは、この設定をオンにして以降のものだけで、それ以前の内容が遡って保存されることはありません。この設定はいつでもオフに戻せます。

安全性とプライバシーを守るため、センシティブな話題の保存をオンにしている場合でも、Claude が保存しない話題があります。社会保障番号や政府発行の身分証明書番号といった機密性の高い識別番号、犯罪歴、移民ステータス、その他 Anthropic の Acceptable Use Policy(AUP)に違反する内容などです。これらの情報を含めてメモリを更新できない場合、Claude はその旨をあなたに知らせます。詳しくは[ヘルプセンター](https://support.claude.com/en/articles/11817273-use-claude-s-chat-search-and-memory-to-build-on-previous-context#h_6fe1d0e66f)をご覧ください。

## **利用を開始する**

メモリは、Free、Pro、Max プランでは web、デスクトップ、モバイルを問わずデフォルトでオンになっています。なお、センシティブな話題をメモリに保存する設定はデフォルトではオフです。iOS および Android では、最新版のモバイルアプリにアップデートすることで最新の更新内容を利用できます。Team および Enterprise では、管理者が組織内での利用可否を制御し、個々のユーザーがオンにするまでメモリはオフになっています。

メモリのオン/オフや Claude が何を覚えるかの制御は、[設定 > メモリ](https://claude.ai/redirect/claude_com.v1.58e756f9-3900-4154-a43b-8f6696b8ed96/new#settings/customize-memory)から行えます。
