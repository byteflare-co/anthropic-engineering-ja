# Claude Marketplace: パートナーのプラグイン、エージェント、サービスを一か所で見つける

本日より、[Claude Marketplace](https://claude.com/platform/marketplace) では、プラグインやコネクタ、エージェントや製品、そしてサービスパートナーを一か所にまとめて提供します。お客様にとっては、必要なツールやサービスを見つけるための単一の窓口となります。ビルダーやパートナーにとっては、Claude を利用するチームにリーチするためのより簡単な手段となります。

## **お客様向け: Claude をもっと活用するためのツールとサービスを見つける**

Claude Marketplace は、チームが Claude の活用の幅を広げるために必要なものを見つける場所です。次のようなことができます。

- **コネクタとプラグインを追加する。** Atlassian、Google、Microsoft、Notion、Salesforce など、本日時点で2,000以上の選択肢から選べます。
- **エージェントと製品を購入する。** CrowdStrike、Cursor、Harvey、Legora、Lovable、Snowflake といった企業の Claude 搭載ソフトウェアに、Anthropic へのコミット済み利用額の一部を充てられます。
- **サービスパートナーとともにスケールする。** Accenture、Boston Consulting Group、Deloitte など、[Claude Partner Network](https://partnerhub.claude.com/directory/) のコンサルティングパートナーやシステムインテグレーターとつながり、AI戦略の構築や組織全体への Claude 展開を進められます。

![](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/6ab3af144435c228297042ed_Claude-marketplace.png)

## **ビルダーとパートナー向け: Claude を利用するチームに見つけてもらう**

Claude のお客様向けにツール、製品、サービスを構築する企業は、Claude Marketplace に掲載できます。提供する内容に合った方法を選んでください。

- **Claude を利用するチーム向けに構築していますか?** Model Context Protocol (MCP) と Agent Skills という、Anthropic が先駆けたオープンスタンダードを使って、[コネクタ](https://claude.com/docs/connectors/building/submission)や[プラグイン](https://claude.com/docs/plugins/submit)を作成してください。
- **Claude 搭載のエージェントや製品を販売していますか?** マーケットプレイスへの掲載を[申請](https://claude.com/marketplace-partners)してください。チームはコミット済みの Anthropic 利用額の一部を使って購入できるようになります。
- **コンサルティングやシステムインテグレーションを提供していますか?** [Claude Partner Network](https://claude.com/form/cpn-partner-application) に参加してマーケットプレイスに掲載され、Claude のお客様から見つけてもらい、つながることができます。
