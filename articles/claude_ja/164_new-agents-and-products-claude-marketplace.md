[Claude Marketplace](https://claude.com/marketplace) に新しいエージェントとプロダクトを追加しました。Claude Marketplace は、チームが Claude をさらに活用するためのパートナーツールやサービスを見つけられる場所です。今回の追加は、セキュリティ、開発者向けインフラストラクチャ、クリエイティブ、生産性の各分野にわたります。

対象となるエンタープライズのお客様は、Anthropic とのコミット済み利用額の一部をこれらのソリューションに充てることができます。新しいものを購入する場合でも、すでに利用しているプラットフォームの利用を拡大する場合でも、Claude とパートナー製品の両方に単一のコミットメントを活用できます。

現在、マーケットプレイスには 25 を超えるパートナーのエージェントとプロダクトが掲載されています。ここでは、最新の追加内容と、それぞれでチームが何をできるのかを紹介します。

## **コードとシステムを保護するためのプロダクトとエージェント**

**[Chainguard](https://claude.com/marketplace/agents-products/chainguard):** Chainguard Harness は、隔離された microVM 内でソースからアプリケーションをビルドし、稼働中のアプリに対して悪用可能な脆弱性がないかを調査します。再現可能な脆弱性に対してカスタマイズされた修正の推奨事項を提示し、Claude が見つけた問題をチームが修正できるよう支援します。

**[Checkmarx](https://claude.com/marketplace/agents-products/checkmarx):** Checkmarx One は、ルールベースの分析と AI による推論を組み合わせて、コード内の脆弱性を検出します。チームが検出結果に優先順位を付け、コードをリリースする前に修正できるよう支援します。

**[Cyera](https://claude.com/marketplace/agents-products/cyera):** Cyera Agent Guardian は、Claude のデプロイメントを棚卸しし、Claude の実行前に権限を管理し、プロンプト、ファイル、ツール呼び出しに対してポリシーを適用します。また、レッドチーミングを通じてそれらの制御をテストできるよう支援します。

**[Rubrik](https://claude.com/marketplace/agents-products/rubrik):** Rubrik Code Guardian は、Anthropic のフロンティア AI モデルを使用して、GitHub または Azure DevOps リポジトリのセキュアなコピーを対象に、複数ステップにわたる攻撃経路をレビューします。セキュリティチームとエンジニアリングチームが問題を深刻度順にランク付けし、確認された重大な問題を追跡可能なチケットに変換できるよう支援します。

**[Tanium](https://claude.com/marketplace/agents-products/tanium):** Tanium Cloud は、エンドポイント全体にわたるリアルタイムの可視性と制御をチームに提供します。IT チームとセキュリティチームが、脆弱性、設定ミス、未適用のパッチを発見して修正できるよう支援します。

## **エンジニアリングチーム向けの開発インフラストラクチャ**

**[Datadog](https://claude.com/marketplace/agents-products/datadog-agent-observability):** Datadog Agent Observability は、ツールやサービスをまたいでエージェントの実行をトレースします。本番環境でのパターンを可視化し、修正を推奨することで、チームがエージェントの品質、パフォーマンス、コスト効率を改善できるよう支援します。

**[Netlify](https://claude.com/marketplace/agents-products/netlify):** Netlify Enterprise は、アプリ、サイト、エージェントをグローバルなエッジネットワークにデプロイし、変更ごとにプレビュー URL を提供します。インフラストラクチャを設定することなく、Claude で構築したものをプロトタイプから本番環境へと移行できるよう支援します。SSO、ロールベースのアクセス制御、監査ログも備えています。

## **マーケティングとクリエイティブ業務のためのツール**

**[AirOps](https://claude.com/marketplace/agents-products/airops):** AirOps は、AI 検索戦略、コンテンツ、マルチチャネルでの施策実行のためのエージェント型プラットフォームを提供します。マーケティングチームが AI 検索におけるブランドのパフォーマンスを分析し、その成果をパイプラインや売上に結び付けられるよう支援します。

**[Runway](https://claude.com/marketplace/agents-products/runway):** Runway は、動画、画像、音声を生成・編集します。クリエイティブチームとマーケティングチームが、ブリーフを完成したアセットに仕上げたり、自然言語で映像を編集したりできるよう支援します。

**[Webflow](https://claude.com/marketplace/agents-products/webflow):** Webflow は、Web サイトを構築、管理、最適化するための組み込みツールを提供します。制御機能とガバナンスを備えた環境で、マーケター、デザイナー、開発者、そしてエージェントが変更を加えられるよう支援します。

## **あらゆるチームのための生産性アプリ**

[**Asana**](https://claude.com/marketplace/agents-products/asana): Asana AI Teammates は、Asana Work Graph のコンテキストを活用する構築済みのエージェントで、それぞれが独自のアイデンティティ、範囲を限定した権限、監査証跡を持ちます。判断が必要な意思決定は担当者に回しつつ、チームが複数ステップの業務を処理できるよう支援します。

**[Glean](https://claude.com/marketplace/agents-products/glean):** Glean は、システムをまたいで社内のナレッジとワークフローをつなぎます。従業員が答えを見つけ、接続されたアプリをまたいで複数ステップのタスクを完了できるよう支援します。

**[monday](https://claude.com/marketplace/agents-products/monday):** monday のエージェントは、プロジェクト、ボード、ドキュメント、ミーティングの中で動作し、それらの担当者や期限をコンテキストとして活用します。PMO、IT、マーケティング、財務、オペレーションの各チームが、AI がアクセス、承認、支出できる範囲を制御できるよう支援します。

[**Zoom:**](https://claude.com/marketplace/agents-products/zoom) Zoom Agentic Search は、最新のミーティング要約、業務上の会話、ドキュメント、接続されたサードパーティのソースを使って、Claude の中で質問に回答します。チームは、生の文字起こしを分析したりツールを連鎖させたりすることなく、権限を考慮した結果を得られます。

## **はじめに**

すべてのエージェントとプロダクトは [Claude Marketplace](https://claude.com/marketplace/agents-products) で閲覧でき、どの掲載製品からでも購入をリクエストできます。Claude 上で開発を行っていてマーケットプレイスへの参加を希望される場合は、[参加方法](https://claude.com/marketplace#join)をご覧ください。
