# Claude Cowork プロダクトガイド

ほとんどの AI ツールは会話型です。質問をすると答えが返ってきますが、その答えを実際に役立つ何か——スライド資料、ドキュメント、スプレッドシート、メール——に仕立てる作業は、依然として手作業のままです。

私たちの新しいナレッジワーク・エージェント、Claude Cowork を使えば、こうした作業を Claude に任せられます。あなたは、より戦略的・創造的な問題の解決に集中できるようになります。Claude デスクトップアプリ上で動作する Claude Cowork は、ローカルファイルを読み書きし、Slack や Google Drive といった連携アプリをまたいで作業し、複数ステップのタスクを実際の成果物までやり遂げます。引用元として参照した実ファイルやメッセージへのリンクも添えます。あなたはゴール、望む成果、頻度を伝えるだけで、Claude が手順を組み立てて仕事を進めます。その間、あなたは各ステップに常に関与できます。

すぐ使い始められるよう、Claude Cowork の実践的なプロダクトガイドをまとめました。次の内容を扱っています：

- 会話型 AI ツールとは異なる **Claude Cowork の特長**と、ローカルファイルアクセス、サブエージェント、長時間タスク、スケジュールタスクといったコア機能
- **どのツールをいつ使うかを整理したプロダクト・マトリクス**：会話形式のドラフトには chat を、コーディングには Claude Code を、アプリ横断のナレッジワークには Claude Cowork を
- **セットアップとシステム要件**、パーミッションモデル、まず試すべきこと
- リサーチブリーフ、会議準備、定期レポートなど **Claude Cowork のよくある 7 つのワークフロー**
- マーケティングやプロダクトマネジメントといった特定のナレッジワークに向けた **プラグインの使い方**
