# HCLTech が Global Premier パートナーとして Claude Partner Network に参加（HCLTech joins the Claude Partner Network as a Global Premier partner）

Anthropic は、60 か国で 23 万人以上の従業員を擁するグローバルテクノロジー企業 [HCLTech](https://www.hcltech.com/) とパートナーシップを結びます。HCLTech は、専任の Anthropic Business Unit と Center of Excellence を通じてクライアント向けに Claude を基盤としたエージェント型ソリューションを構築するほか、HCLSoftware の製品に Claude を組み込み、クライアントの IT サービス運用に用いるプラットフォーム AI Force に Claude と Claude Code を統合します。HCLTech は Claude Partner Network の最上位ティアである [Global Premier Partner](https://claude.com/partners) となります。このティアには 1,000 名の[認定実務者](https://claude.com/resources/articles/four-role-based-claude-certifications)が必要です。

HCLTech は、金融サービス、製造、ライフサイエンス・ヘルスケア、テクノロジー、半導体、通信・メディア、小売・消費財（CPG）、モビリティ・公共サービスの各分野にソリューションを提供しています。こうした環境では、ミスは高くつき、あらゆる変更がレビュー・記録・承認を必要とします。今回のパートナーシップは、そうした環境向けに設計された統制を備えたうえで、Claude をこれらの業務に組み込むためのものです。

## **HCLTech が Claude をどのように活用しているか**

HCLTech は 3 つの領域で Claude を事業に取り入れており、それぞれにガードレールと人間によるレビューを組み込んで設計しています。

- **専任の Anthropic Business Unit と Center of Excellence。** HCLTech の Forward Deployed Engineer が安全なサンドボックス環境を構築し、クライアントは本番導入の前に自社のシステムとデータを使って Claude を検証できます。Center はクライアントの従業員のトレーニングを行い、エンジニアリングチームの AI ネイティブな開発手法の導入を支援し、エージェントを大規模かつ安全に運用するための組織的な統制を構築します。
- **HCLSoftware 製品への Claude の組み込み。** HCLSoftware は Anthropic の独立系ソフトウェアベンダー（ISV）パートナーとなり、サイバーセキュリティ、オートメーション、ビジネスプロセスアプリケーション、アプリケーション開発の各分野の一部製品に Claude を組み込みます。最初の対象は、エンドポイント管理の HCL BigFix、アプリケーションセキュリティテストの HCL AppScan、そしてデータ・アナリティクス向けの Actian AI analyst です。
- **AI Force における Claude と Claude Code。** AI Force は、HCLTech が顧客企業に IT サポート、コード修正、デジタル従業員サービスを提供するための基盤です。Claude と Claude Code は、ポリシーのガードレールと例外処理を備えた形でこのプラットフォームに組み込まれます。定型的な作業はエージェントが担い、影響の大きい変更は HCLTech のエンジニアが監督します。

「グローバルなシステムインテグレーターとしての規模と、ISV としての製品の厚みを兼ね備えたテクノロジー企業はほとんどありません」と、HCLTech の CEO 兼マネージングディレクターである C Vijayakumar 氏は述べています。「それにより私たちは、エージェント型 AI を安全に設計して大規模に展開し、クライアントにとって最も重要なビジネス成果を届けるうえで、稀有な優位性を持っています。Anthropic とのパートナーシップは、それを実現する私たちの能力をさらに強化するものです。」

「AI の有用性は、その信頼性があってこそです。私たちは、企業が最も機密性が高く価値のある業務に安心して導入できるよう Claude を開発しています」と、Anthropic の共同創業者兼プレジデントである Daniela Amodei は述べています。「HCLTech は銀行、病院、通信会社、製造業者のためにまさにそうしたシステムを管理しており、Claude と Claude Code の統合を進める同社とパートナーシップを組めることを嬉しく思います。このパートナーシップ、そして能力と安全性をともに前進させるという私たちのより広いコミットメントこそが、AI によって業界全体の運営をより良い方向へと変えていく道筋です。」

Anthropic のパートナーとの協業について詳しくは、[Claude Partner Network](https://claude.com/partners) をご覧ください。
