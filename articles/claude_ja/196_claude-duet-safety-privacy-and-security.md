# Claude Duet の安全性、プライバシー、セキュリティ（Claude Duet Safety, Privacy, and Security）

[Claude Duet](https://claude.com/resources/articles/claude-duet) は、クラウド上のコンピュータを使ってあなたの代わりに仕事をこなすエージェントで、現在リサーチプレビュー中です。あなたが Claude に接続したすべてのアプリやサービスを利用でき、アプリを閉じた後も動き続けます。あなたが不在の間に、受信トレイを読み、返信の下書きを作り、予約を行い、ルーティンを実行できます。私たちのチームも自分たちのアカウントで Claude Duet を動かし、毎日の仕事に使っています。

私たちは、エージェントの振る舞いを導く 3 つの原則に基づいて Claude Duet を構築しました。

1. あなたの情報や、接続されたアプリ内で他の人が共有した情報は、慎重に扱われます。そのために、Claude Duet が下書きしたメッセージを送信前にチェックする新しい分類器を用いています。
2. あなたの代わりに何を行うかは、常にあなたがコントロールします。
3. Claude Duet が、あなたのパスワード、ブラウザの Cookie、サインイントークン、その他の認証情報を目にすることはありません。

Claude Duet は新しい製品ですが、その背後にある考え方は新しいものではありません。2025 年、私たちは[安全で信頼できるエージェントのためのフレームワークを公開しました](https://www.anthropic.com/news/our-framework-for-developing-safe-and-trustworthy-agents)。このフレームワークは人間を主導権のある立場に置き、プライバシーと安全なやり取りを基本要件として扱うものです。それ以降も、[単一の防御策だけでは十分でない](https://www.anthropic.com/research/trustworthy-agents)理由や、[モデル内部の保護だけに頼ることはできない](https://www.anthropic.com/engineering/how-we-contain-claude)理由について書いてきました。また私たちは、企業が本番環境でエージェントを動かすためのインフラを [Claude Managed Agents](https://www.anthropic.com/engineering/managed-agents) を通じて構築・運用しており、Claude Duet も同じ方法で認証情報をエージェントから切り離しています。Claude Duet はこれらの取り組みを土台に、あなたの代わりに行動するエージェントに必要な保護を追加したものです。本記事では、私たちが何を追加したのか、そしてまだ取り組んでいることは何かを順に説明します。

## 重要なアクションはあなたが承認する

あなたの不在中に行動するエージェントは、先に進む前に立ち止まって許可を求めるべきタイミングを知り、それを適切な頻度で行う必要があります。機密性の高い可能性があるメッセージの送信、支払い、何かの削除といった操作を行う前に、Claude Duet はそのアクション、送信先、内容（すべての受信者を含む）をあなたに提示します。そして、あなたがそのアクションを承認するのを待ちます。

各アクションと並行して、別の自動チェックが実行されます。これは [Claude Code の auto mode 分類器](https://www.anthropic.com/engineering/claude-code-auto-mode)をベースに、Claude Duet 向けに拡張したものです。このチェックは、そのアクションがあなたの意図に沿っているかを評価します。作業を行うモデルの外側で実行されるため、ページ内に隠された指示が結果に影響を与えることはできません。

あなたの承認があっても禁止されたままのアクションもあります。たとえば証券の売買、口座間の資金移動といった銀行操作、他人のアカウントへのアクセスなどです。また、どれだけ頻繁に承認してきたとしても「今後は確認しない」ルールの対象にならない手順もあります。支払いや送金、注文の削除、アカウントの作成などがそれにあたります。あなたの不在中に実行されるルーティンにも同じ安全策が適用されます。

私たちは、Claude Duet が承認を求める頻度の調整に多くの時間を費やしました。承認疲れは深刻な問題です。リクエストが多すぎると、人は十分に検討しないまま次々とタップして承認するようになってしまうからです。この調整は今後も継続して見直していきます。

購入の際、Claude Duet は Link from Stripe のようなウォレットが発行する使い捨てカードで支払います。このカードはその加盟店と金額に限定されています。あなたは商品と合計金額を確認し、Link アプリで購入を承認します。あなたの実際のカード番号が Claude Duet や加盟店に共有されることはありません。

![Claude Duet の承認フローを示す図](https://assets.claude.com/45eff23b993c919b077fb5c7f366c78bcfb7c06d.png)

図 1. 承認フロー：承認カードと独立したチェックはモデルの外側にあるため、エージェントが読み取ったものが承認カードに応答することはできません。

## あなたの情報は慎重に扱われる

あなたのメールを読み、あなたの代わりにメッセージを送るエージェントは、さまざまな種類の情報をどこに送るべきかを常に判断しています。たとえば Claude Duet にチームへの週次まとめの送信を頼んだ場合、そこにはチームの全員がすでにアクセスできる内容だけを含めるべきであり、人事評価の面談内容のようなプライベートな詳細は決して含めてはいけません。

この課題に対処するため、私たちはメインモデルとは別に動作する新しい安全性分類器を構築しました。この分類器は、Claude Duet が送信しようとしている各メッセージに、機密性の高い可能性がある情報が含まれていないかをチェックします。こうした情報は 2 つの段階に分類しています。

- **決して共有しない：** サインイン用の認証情報、カード番号や銀行口座番号の全桁、政府発行の ID 番号といった情報には、最も強い保護をかけています。Claude Duet は、たとえあなたに頼まれても、これらを誰とも共有しないよう指示されています。
- **共有には同意が必要：** 健康や財務といったその他のプライベートな情報については、あなたが明示的に承認した場合にのみ共有します。あなた自身の依頼は同意とみなされるため、「歯の痛みについて歯医者さんにメモを送って」といった依頼では、通常は追加の承認は不要です。

![Claude Duet であなたの情報がどこに送られうるかを示す図](https://assets.claude.com/6cf6546eabf0f7bdccd66fa93e407941f9e50947.png)

図 2. あなたの情報が送られうる先：何かが送信される前に、チェックは情報の機密性の高さと、あなたが同意しているかどうかを検討します。

いずれかの理由で Claude Duet がブロックされた場合、機密情報を除いた形でメッセージを書き直し、あなたに承認を求めることがあります。

Claude Duet はまだリサーチプレビュー段階であり、これらの安全策が何かを見逃したり、無害なメッセージを誤って検出したりすることもあります。だからこそ、これらの安全策は前述の承認の仕組みと組み合わせて機能します。承認の仕組みは、Claude Duet があなたの代わりに何を送るかをあなたがコントロールできるよう設計されています。人々が Claude Duet をどのように使うかについて理解が深まるにつれ、分類器も改善を重ねていく予定です。

## タスクと接続アプリを把握できる

Claude Duet がこれまでに行ったことや現在行っていることは、タスクリストで確認できます。各タスクには専用のページがあり、タスクの途中で方向修正することもできます。Claude Duet は、タスク間でコンテキストを引き継げるよう、あなたが履歴を削除するかリセットするまで、会話履歴とメモリを保持します。アカウントを削除すると、Claude Duet が保存したものはすべて消去されます。

![Claude Duet のタスクリストの画面](https://assets.claude.com/2ea9a7ae6dfe5a96c7e3e0fb759df5a0703704b1.png)

Claude に接続したアプリは Claude Duet にも引き継がれ、どちらか一方でアプリをオフにすると、両方でオフになります。アプリの接続を解除すると、その時点から新たなアクセスは停止しますが、Claude Duet がそのアプリからすでに学んだ内容は、メモリをリセットするまで残ります。メモリのリセットはアプリの設定からいつでも行えます。また Claude Duet はあなたの Claude アカウントのメモリも利用するため、以前のチャットで Claude が記憶した詳細も参照できます。

## 認証情報とブラウザはモデルから隔離されている

Claude Duet が、あなたのパスワード、ブラウザの Cookie、接続アプリのサインイントークンを目にすることはなく、それらをメモリに保存することもできません。これらは、モデルがアクセスできない別のマシンだけを経由します。Claude Duet の行動を管理する承認や安全性チェックも、そこで実行されます。

**パスワード**

サイトがパスワードを求めてきたときは、Claude アプリ内のフォームにパスワードを入力します。フォームは、私たちの安全なクラウドブラウザマシン上にのみ存在する、その 1 回限りの使い捨て鍵でパスワードを暗号化します。暗号化されたパスワードは開封されないままブラウザに渡され、ブラウザがそれをサイトに入力します。モデルはパスワードを目にすることがなく、保存したり繰り返したりすることもできません。近いうちに 1Password でのサインインにも対応する予定です。Claude Duet が認証情報を要求し、あなたが 1Password でそのリクエストを承認すると、認証情報はモデルを経由せずにブラウザへ送られます。

あなたの代わりにサインインするエージェントは、フィッシングのあり方を 2 つの点で変えます。一方で、Claude Duet はあなたの認証情報を保持していないため、パスワードを騙し取られることはなく、隠された指示によって持っていない秘密を明かさせることもできません。他方で、サインインフォームそのものが標的になります。パスワードを求めるものは何であれ模倣されうるからです。そのため Claude Duet のサインインフォームは、あなたが依頼したサインインの最中に、アプリ内でのみ表示されます。リンク、テキストメッセージ、メール、あるいは claude.ai 以外のウェブサイトとして届くことは決してありません。Claude Duet のように見える何かがそれ以外の場所でパスワードを求めてきたら、それは正規のものではありません。

**サインイントークン**

接続アプリで作業する際、Claude Duet は [Claude Managed Agents の設計](https://www.anthropic.com/engineering/managed-agents)に従い、認証情報をエージェントの作業から手の届かない場所に置きます。接続サービスのサインイントークンなど、エージェントがあなたの代わりに使う認証情報は、エージェントが作業するマシンには決して入りません。代わりにそこには認証情報のプレースホルダーが置かれ、そのマシンの外にあるプロキシが、リクエストが行われる時点でのみ実際の値を差し込みます。

**ブラウザ**

Claude Duet におけるあなたのブラウザは、クラウド上の専用の仮想マシンで動作し、モデルからも、エージェントが作業するクラウドコンピュータからも分離されています。エージェントは、*このページを開く、ここをクリックする、これを入力する*といった決められたコマンドセットを通じてのみブラウザを操作します。サイトが実行するものはすべて[ブラウザマシン上にとどまります](https://www.anthropic.com/engineering/managed-agents)。サイトのコードや Cookie が Claude Duet のメモリや接続アプリに届くことはなく、エージェントのどのコマンドもブラウザから Cookie を読み出すことはできません。戻ってくるのはページのテキストとダウンロードファイルです。エージェントが仕事をするにはそれらを読む必要があるからです。だからこそ他のチェックが存在し、Claude Duet は[ブラウザ操作に関する研究](https://www.anthropic.com/research/prompt-injection-defenses)で説明したプロンプトインジェクション対策も用いています。ブラウザ経由でアップロードするファイルにも、メッセージと同じ機密情報チェックが適用されます。

![Claude のコンピュータ上で行われることと、あなたのコンピュータに残るものを示す図](https://assets.claude.com/7df447f5c9bcaa1b3424f88f94d623be1383b637.png)

図 3. ブラウザの境界：決められたコマンドが送られ、ページのテキストが戻ってきます。サイトのコード、Cookie、ダウンロードはブラウザマシン上にとどまります。

Claude Duet は、自らがエージェントであることを明示するようにも設計されています。現在、そのウェブブラウザが送信するリクエストには固有の User-Agent ヘッダーが含まれており、ブラウジングに使う公開 IP アドレスも公表しています。これにより、サイト側は Claude Duet を識別し、どう扱うかを判断できます。ローンチ前には、いくつかの大規模ウェブサイトに連絡を取り、Claude Duet による訪問を拒否する選択肢を提供しました。実際に拒否を選んだサイトもあります。リサーチプレビューから学びながら、Claude Duet の名乗り方を今後も改善していきます。

![パスワードの認証情報の経路を示す図](https://assets.claude.com/3073b7d3f85e65f58bd4a7627eb5f5ff9c2af4af.png)

図 4. 認証情報の経路：パスワードはあなたのスマートフォン上で暗号化され、ブラウザマシン上でのみ開封され、モデルを経由することはありません。

## Claude Duet のテスト方法

テストはリサーチプレビューのかなり前から始まり、現在も続いています。私たちの Safeguards チームは、ルーティン型のタスクから評価を構築しました。各タスクには 3 つのバリエーションがあります。無害なもの、指示が注入されたもの、そして頼まれた以上のことをするようエージェントを誘惑するものです。これらの評価は、実際の利用から得たシャドートラフィックと並行して実行されています。

さらにレッドチームが、Claude Duet が情報を漏らさないか、承認なしに行動しないか、悪意あるプロンプトに従わないかをテストしました。私たちは、システムが関わるリポジトリや信頼境界全体にわたって、システム全体の脅威モデルを構築しました。外部のペネトレーションテスト企業が、私たちのソースコードへのアクセス権を持った状態で Claude Duet をテストし、現在はクラウドブラウザとサインインフォームを対象とした追加の検証が進行中です。新しい認証情報関連の機能はいずれも、誰かに提供される前に、隔離された環境でレッドチームによるテストを受けます。

Claude Duet は Anthropic の公開バグバウンティプログラムの対象にもなっています。このプログラムでは、責任ある開示ポリシーのもとで、有効な報告に報奨金を支払い、善意の研究にはセーフハーバーを提供しています。セキュリティ上の脆弱性を見つけた場合は、ぜひお知らせください。[HackerOne](https://hackerone.com/anthropic) 上の Anthropic のバグバウンティプログラムから報告できます。

## 皆さんとともに作り上げる

私たちが Claude Duet をリサーチプレビューとして公開するのは、パーソナルエージェントに皆さんが何を求めているのか、次にどのような保護や制御を望んでいるのかを知りたいからです。本記事で説明した内容の一部は、今も変化し続けています。承認を求める頻度、サインインの方法、そして機密情報チェックがプライベートなものと無害なものをどれだけうまく見分けられるか、といった点です。見てみたい機能や、うまくいかなかったことを Claude Duet に普段の言葉で伝えてください。Claude Duet が私たちのチームに向けてレポートを提出します。
