# Millennium と Anthropic が Claude でデジタルリスクアナリストを構築

Anthropic は、世界最大級のオルタナティブ投資運用会社の一つである Millennium と協力し、デジタルリスクアナリストを共同開発しています。これは、同社のリスクマネージャーと並んで、その監督のもとで働く AI チームメイトであり、新たなリスクインサイトを発見し、資産クラス全体にわたるリスクエクスポージャーについて見解を形成します。

Claude と [Claude Code](https://claude.com/product/claude-code) は、トレーディングデスクやエンジニアリングからコアビジネス機能に至るまで、すでに Millennium 全体で広く使われています。Millennium のデジタルリスクアナリストは、リスクマネージャーによるリスクポジションの分析を迅速化・充実させることで、Claude の活用範囲をさらに拡大します。

## Claude で金融リスクを評価する

投資会社はこれまで数十年にわたり、リスク測定を改善するために技術を活用してきました。従来型の評価から、より複雑なリアルタイムのシナリオ分析へと進化してきたのです。Millennium のデジタルリスクアナリストは、Millennium 独自のデータと Claude のフロンティア知能を活用し、重要なワークフローに取り組むよう設計されています。

デジタルリスクアナリストは、時間をかけて情報を保持・想起し、新しい推論能力を適用して日々のリスク変動を説明する助けとなります。これらの分析結果は、その後 Millennium の人間のリスクマネージャーによって検証・拡充されます。

「Millennium では、AI が私たちの人材が達成できることの新たな基準を打ち立てる助けになると信じています」と Millennium の最高情報責任者(CIO)である Vlad Torgovnik 氏は語ります。「Anthropic との取り組みはその好例であり、人間の判断を意思決定の中心に据えながら、AI がビジネスの中核部分でイノベーションを推進する様子を示しています。業界のリーダーである Anthropic との取り組みを継続し、AI が私たちのビジネスに価値を加える新たな方法を見つけていくことを楽しみにしています。」

## Millennium の従業員による Claude の活用方法

Millennium は Claude と Claude Code の早期導入企業です。従業員は Claude Code を使ってソフトウェアを書き、プロダクトを構築し、ワークフローを改善しています。これは Millennium の 340 を超える投資チームの多くにわたって行われています。

デジタルリスクアナリストは、その推論を記録し、サンドボックス環境でアクションをテストし、人間の専門家による評価と承認を必要とすることで、安全で監査可能な分析を提供します。Millennium のリスク専門家は、Anthropic のリサーチチームとアプライドAIチームが Millennium の AI ラボで共に働きながら、これを構築しています。

Millennium は社内の AI ラボを活用してフロンティアを押し広げ続けており、Anthropic の最新の Claude モデルを野心的なユースケースに対してプレッシャーテストし、Claude をペースの速い環境でのイノベーションに役立てています。

「金融サービスには、複雑で要求の厳しい環境でも人々が信頼できる AI が必要です」と Anthropic の金融サービス担当マネージングディレクターである Belinda Neal 氏は語ります。「Millennium は Claude と Claude Code の早期導入企業であり、同社のリスクチームとの取り組みは、AI が Millennium のリスクマネージャーが日々行う分析にどのように情報を提供できるかを示すものになるでしょう。」

「Claude はリスクポジションを推論し、日々の変動を説明し、学んだことを次の問いへと引き継ぐことができます」と Anthropic の資産・資産運用(Asset and Wealth Management)責任者である Peter Nolan 氏は語ります。「Millennium のリスクマネージャーは、フロンティア知能を活用して自動化されたレコメンデーションを提供し、貴重な時間を節約することを目指します。」
