# Claude Cowork とチャットが1つの Claude に

本日より、Claude Cowork とチャットは1つの Claude に統合されます。ちょっとした質問を持ちかけても、正午締め切りのレポートを任せても、Claude がそのまま引き受け、あなたがノートパソコンを閉じた後も作業を続けます。今後数週間かけて Pro プランと Max プランに展開され、他のプランも追って対応予定です。

Claude が作成するものについても、専用の置き場所は不要になりました。本日から Claude Docs と Claude Slides が新たに登場し、[Claude Design](https://claude.com/product/design) も会話の中で使えるようになります。ドキュメントを依頼すれば、あなたと Claude が一緒に書き上げます。プレゼンテーションを依頼すれば、Claude がスライドの草案を作成します。直接編集することも、Claude からそのままプレゼンすることも、PowerPoint や PDF としてダウンロードすることもできます。3つとも有料プランでベータ提供され、Enterprise の管理者はいつ有効化するかを選べます。Claude Design を単独で使っている場合は、これまで通り動作し続けます。

私たちは Cowork を大きな作業のための独立した場所として、Design を視覚的な作業のために作りました。多くの人が両方を使い、もどかしいのはどちらにタスクを振り分けるかを決めることだと教えてくれました。一方で始めたことが、もう一方には引き継がれないという問題もありました。そこで、選ばせるのをやめることにしました。Claude は今やタスクに何が必要かを自ら判断できるため、Cowork と Design にできることは、あなたがすでに持っているコンテキスト、スキル、コネクタとともに、どの会話からでも利用できます。

> *「[私の法律調査データベース]を Claude に開かせれば、すべての判例を取り込んで読み込み、他にどの判例が必要かを判断し、ダウンロードして、個人レビュー用のフォルダに保存してくれます。」 - アンドリュー・ケラー、シニアエコノミスト*

## 実際の使い方

正午に週次レポートの締め切りがあるとします。出かける前に、先週パイプラインで何が動いたかを Claude に尋ね、こう付け加えます。「いつも通りの形式で書いて、遅延しているものにはフラグを立てて、要点をリーダーシップミーティング用に5枚のスライドにまとめて」。不明な点があれば Claude が質問してきます。オフィスに向かう途中、スマートフォンから進捗を確認できます。デスクに着く頃には、レポートはチームメイトからのコメント付きのドキュメントとして仕上がっており、スライドも開いて調整し、PowerPoint としてダウンロードできる状態になっています。両方とも同じ会話から生まれたものなので、スライドはすでにレポートと整合しています。自分で一行修正し、スライドに Claude 宛てのコメントを残して共有します。毎週月曜日にスケジュール設定しておけば、Claude は指示されなくてもレポート作成に取りかかります。

Claude Design、Slides、Docs で作成したものはすべて、1つの共有可能なリンクとしてスマートフォンからも開くことができます。要素を選択して移動させたり、Claude に変更内容を伝えたりできます。

Claude がどのように確認を取るかは選択できます。デフォルトでは、Claude は行動を起こす前に確認を求めます。作業を続けさせて、注意が必要なときだけ確認してほしい場合は、その設定をオンにできます。最終判断は常にあなたが下します。

## 使い始める

主にチャットを使っている場合、特に変える必要はありません。もっと大きなことを任せたくなったら、次に自分で作るはずだったレポートやデッキで試してみてください。すでに Cowork で作業していた場合は、チャット、プロジェクト、アーティファクト、コネクタ、スキルなど、すべてそのままの状態で残っています。アプリを開けば、やめたところから再開できます。

これはまず Pro プランと Max プランを対象に、Web・デスクトップ・モバイルの Claude アプリで、これらのプランの既存および新規ユーザー向けに今後数週間かけて展開されます。特に何かをオンにする必要はありません。Team プランと Free プランも近く追随する予定で、Enterprise の管理者には、組織に変更が及ぶ少なくとも30日前に連絡があります。

機能の全リストは[ヘルプセンター](https://support.claude.com/en/articles/16761823)に掲載されています。ずっと溜め込んでいた、大きくて雑然としたプロジェクトがあるなら、今がその時です。
