# Microsoft Foundry の Claude が一般提供開始

本日より、Claude モデルは Azure 上にホストされる Microsoft Foundry で一般提供（GA）となります。Claude はお客様の Azure 環境内で動作し、チームがすでに利用している認証、請求、ガバナンスのコントロールがそのまま適用されます。データレジデンシー要件のあるチーム向けに、米国データゾーンを含む推論処理の場所を選択できます。推論は Anthropic が運用し、データプロセッサーは Anthropic です。

![Logo](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/6a204b023a1098addb579701_6a204a9b15a9f95c27630dc2_NVIDIA_light.svg)![Logo](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/6a2859e3adf1957b476f9302_NVIDIA_dark.svg)

「NVIDIA では、自律型 AI エージェントを毎日活用して、チームがより速く動き、より大きく考えられるようにしています。Claude モデルは、複雑な技術的作業に価値のある、強力な推論、コーディング、エンタープライズ機能を提供してくれます。Claude が NVIDIA GB300 GPU 上で動作する Microsoft Foundry で利用可能になったことで、より多くの組織が、本番環境に求められるパフォーマンス、スケール、セキュリティを備えた、高度で特化型の AI エージェントを動かせるようになります。」
