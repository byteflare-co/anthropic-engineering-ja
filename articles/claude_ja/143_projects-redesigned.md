# プロジェクトを再設計:フォルダから会話へ

これまで、ビルド全体にまたがる複数のセッションを管理するには、作業を分割し、引き継ぎをやりくりし、結果をつなぎ合わせる必要がありました。今では Claude Code のプロジェクトで、やるべきことを説明するだけで、Claude が作業を管理してくれます。

Claude はリクエストの範囲を定め、作業を委任し、並行するスレッドを調整し、成果物をレビューし、完成した結果を組み立てます。あなたはスマートフォンからでも進捗をずっと導くことができ、Claude はあなたがパソコンから離れた後も作業を続けます。

例えば、プロジェクトを設定してアプリのチェックアウトの p75 レイテンシーを削減するという目標を立てるとします。すると Claude に各エンドポイントをプロファイリングし、最適化をテストし、並行するスレッドで PR を開くよう依頼できます。あるいは API・Web・モバイルのリポジトリを接続し、非推奨になった v1 エンドポイントを廃止するという目標を設定すれば、Claude はリポジトリごとにスレッドを作成して呼び出し元を移行し、テストを実行し、PR を開き、どれを先にマージすべきかを教えてくれます。

本日より、更新されたプロジェクトは、Claude Code でクラウドセッションを使用していて、Web またはデスクトップに既存のプロジェクトを持たない一部の Claude Pro および Max サブスクライバーにベータ版として提供されます。

今後1週間で、これらのプランの Claude Code ユーザーへの展開を拡大していきます。Team プランと Enterprise プランを含むすべての Claude プランでの更新されたプロジェクトの提供は、その後になります。Pro または Max をお使いでまだアクセスできない場合は、[ウェイトリスト](https://claude.com/form/projects)に登録できます。

Pro プランと Max プランの既存のプロジェクトは、これまで通り動作し続けます。展開がチャットと Cowork に拡大するにつれて、それらもアップグレードしていきます。

## スレッドが作業を行い、Claude がそれを指揮する

プロジェクトには、作業を行うスレッドと、それらを指揮するコーディネーターがあります。

プロジェクトを開始すると、目標に加えてリポジトリまたはコンテキストを選択します。Claude はまず、すぐに着手できる作業を提案します。プロジェクトのクラウド環境、コネクタ、プラグイン、指示、モデルを設定することもできます。

![](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/6aac33beedd701b877e2516a_start-new-threads-card-ivory-2524w.png)

メインのプロジェクトチャットで進捗を監視・誘導することも、個々のスレッドに入り込んで詳細を確認し方向づけることもできます。参謀長に指示を出すようにプロジェクトで Claude に指示すれば、新規または既存のスレッドに作業を振り分けます。

Claude は作業の確認とフォローアップも行います。リポジトリが接続されていれば、スレッドは PR を開いてテストを実行します。ドキュメントが接続されていれば、それらを読んで草案を作成します。

内部では、各スレッドは Claude Code のクラウドセッションとして、独自のブランチとリポジトリのコピー上で動作しています。コーディネーターは作業を整理された状態に保ちますが、複数のスレッドが同じコードに取り組んだ場合、その重複は他の PR と同様にマージコンフリクトとして解決されます。

各スレッドは、必要に応じてサブエージェント、ループ、ワークフローを使ってさらに委任された作業を細分化できるため、大きな課題もより速く完了します。

## コンテキストは時間とともに積み上がる

プロジェクトは、1回の返信より時間がかかり、複数の部分から成る作業、つまり長期にわたる、あるいはエージェント的なワークフローのために設計されています。

時間が経つにつれ、Claude はプロジェクトの詳細をより深く学習し、それを作業に活かします。あらゆるスレッドが、今では共有メモリに追加し、そこから引き出すようになり、複雑なプロンプトエンジニアリングの必要性を減らします。

例えば、Claude はリリースが金曜日に延期されたこと、なぜそのエクスポート機能が削除されたのか、課金サービスに触る前に誰に確認すべきかを覚えていることができます。

![](https://cdn.prod.website-files.com/68a44d4040f98a4adf2207b6/6aac17f18b4babdc667d967c_launch-readiness-under-4mb.gif)

*1週間にわたる1つのプロジェクト。各リクエストが右側に新しいスレッドを開き、その下でメモリ、意思決定、結果が積み上がっていきます。*

Claude はあなたの作業スタイルやコミュニケーションスタイルも記憶します。どのくらいの頻度で状況を確認するか、新しいスレッドをどのくらいの頻度で開始するか、各更新をどのくらい詳細にするかを調整するよう依頼できます。

メモリに加えて、プロジェクトには今、追加したファイルと Claude が生成した成果物を集めたライブラリが含まれるようになりました。これにより、関連する資料を見つけやすくなり、新しい作業がこれまでの成果の上に築かれやすくなります。

## 次に控えていること

プロジェクトは複数のスレッドを同時に実行でき、それぞれが完全な Claude Code セッションです。そのため、プロジェクトは使用上限により早く到達することがあります。プロジェクト固有の使用状況を確認し、コーディネーターチャットとワーカースレッドの両方で使用するモデルとエフォートレベルを選択できます。

スレッドは現在クラウド上で実行されていますが、あなたのマシン上でローカルのツールやコードとともに、あなたのネットワークの内側で実行できるようになる機能も間もなく登場します。
