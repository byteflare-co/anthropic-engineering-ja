*2026 年 9 月更新: Claude Design は、Claude Code や Artifacts タブを含む Claude とのあらゆる会話の中で使えるようになりました（有料プランでベータ提供中）。スライドデッキには Claude Slides という専用の出発点が用意されています。詳細は[発表記事](https://claude.com/resources/articles/cowork-is-now-claude)をご覧ください。*

![](https://assets.claude.com/26fe4b872e9039c8736c215fcc8d33a8c933961f.webp)

[Claude Design](https://claude.com/product/design) は、プロジェクトをまたいでデザインシステムに沿い続け、Claude Code とスムーズに連携し、キャンバス上での直接編集が可能になり、普段お使いのより多くのツールと接続できるようになりました。また、Claude デスクトップアプリのサイドバーに新しい居場所ができました。https://claude.com/product/design

私たちの目標はこれまでと変わりません。締め切りの範囲内で通常できるよりも多くの方向性を探れるようにし、仕上げや実装への受け渡しをできるだけ簡単にすることです。そしてこの目標は、今やはるかに多くの人々の役に立っています。最初の 1 週間で 100 万人以上が Claude Design を利用し、皆さんからのフィードバックが次に私たちが作るものを形づくっています。

## デザインシステムのコンポーネントで構築する

柔軟性を高め、精度を向上させるため、デザインシステムのインポート機能を作り直しました。GitHub リポジトリ、デザインファイル、あるいは直接アップロードしたファイルから、1 つまたは複数のデザインシステムを取り込めます。Claude はあなたのコンポーネントを使って構築し、出力をデザインシステムと照合して、あなたが目にする前に修正を加えます。大規模なチーム向けには新たな管理者ロールが用意され、1 つの標準システムを承認して編集をロックできるため、成果物が常に社内ガイドラインに沿ったものになります。

## デザインとコードの間を行き来する

作業を同期させたまま、Claude Design と Claude Code の間を行き来しやすくなりました。/design-sync を使えばデザインシステムを取り込めるので、Claude Design で作るものはすべて既存のコンポーネントから始まります。デザインがソフトウェアにする準備ができたら Claude Code に引き渡せます。Claude Code はスクリーンショットからやり直すのではなく、既存の作業の続きから進めます。

Claude Code から始めたいですか？ デスクトップやターミナルのセッションからデザインを依頼することも、/design を使ってデザインプロジェクトの作成・編集・同期を行うこともできます。デザインをコードベースにインポートしたり、コードをライブプロトタイプに変えたり、プロジェクトを最後まで Claude に任せたりすることも可能です。

> 「Claude Design は、フロンティアモデルの知性と、実績あるデザインツールの機能性を兼ね備えています。Tenex のサイトのデザインの方向性、新しいブランドアセット、プレゼンテーションに取り組むときは、いつも真っ先に Claude Design を開きます。親しみやすい UX と、確かなセンスやデザインの勘を兼ね備えていることが、私の技術スタックの中核になった理由です。さらに、Claude Design と Claude Code の間の受け渡しによって、プロトタイプから本番までのプロセスがシームレスになります。」
> - Alex Lieberman, Cofounder, Morning Brew & Tenex

## 日々の業務に耐える安定性

新しいエディタでは、デザインのあらゆる要素を直接かつきめ細かくコントロールできます。新しい充実したレイアウトコントロールにより、要素のドラッグ、リサイズ、整列が可能です。数百件の安定性修正により、エディタは実際の利用に耐えるものになりました。

また、Claude Design は Claude Code を含む Claude での他の作業と利用上限を共有するようになりました。そのため、ほとんどの方はより多くの余裕を持って制作でき、上限に達していた方もその頻度が少なくなります。

## はじめに

Claude Design は有料プランでベータ提供中です。Pro、Max、Ultra、Team プランではデフォルトで有効になっており、Enterprise プランではデフォルトで無効です。Enterprise では管理者が「Organization settings > Artifacts」から、組織全体または特定のグループに対して有効化します。Team および Enterprise プランでは、リンクはデフォルトで組織内で共有されます。Claude Code を含む Claude とのあらゆる会話の中でデザインを依頼することも、Artifacts タブから始めることも、引き続き [claude.ai/design](https://claude.ai/redirect/claudedotcom.v1.71e8078a-b7b4-4fce-bcc0-338e9c9d7072/design) を使うこともできます。デザインシステムを取り込んで、制作を始めましょう。アイデアが浮かばなければ、次のランディングページについて 3 つの方向性を Claude に依頼し、磨き上げる価値のあるものを選んでみてください。
