# Claude Code と Claude Cowork を政府機関へ

[Claude Code](https://claude.com/product/claude-code) と [Claude Cowork](https://claude.com/product/cowork) が、Claude for Government Desktop のパブリックベータとして利用可能になりました。商用のお客様が使っているのと同じアプリケーション上に構築され、FedRAMP High の認可を受けた環境を通じて提供されます。

Claude Code を使えば、公共部門のチームは公共サービスを支えるソフトウェアシステムを構築・刷新できます。Claude Cowork はデスクトップ上のファイルを直接扱い、省庁のスタッフはメモの作成、RFP のレビュー、ケースワーク、資料作成といった業務を Claude に委任できます。

拡張された今回の体験には、追加のガバナンス機能も含まれています。管理者は構成のデフォルトを設定し、部門横断で支出を割り当てて制御できます。セキュリティチームや認可担当官は、改ざん検知可能な監査ログと、省庁の ATO プロセスをサポートするドキュメントを利用できます。

本日のローンチにより、省庁がその使命の遂行に向けて AI を調達・認可・配分することが、これまで以上に容易になります。

## 新機能

**Claude Code と Claude Cowork。** 省庁は商用ユーザーと同じペースで新機能を利用できます。会話履歴は省庁が管理するデバイス上にローカルに保存されます。推論は FedRAMP High の認可環境内で実行されます。

**予算措置に適合する課金。** プログラムオフィスは、標準シートを使って AI 支出を予算措置と紐づけることも、独自のシートティアを支出上限とモデル制限付きで定義することもできます。利用量は固定単位で購入され、上限を超えない厳格なキャップが設定されます。管理者は管理コンソール上でユーザーごと・モデルごとの利用状況を追跡でき、残高が減ってきたときには自動のバーンダウンアラートが事前に警告します。

**部門構成に合った管理。** 部門レベルの管理者は下位省庁にシートとプリペイド利用量を配分し、各下位省庁が自分たちのユーザーを管理することを許可できます。管理者は SCIM グループマッピングを用いて、特定のシートティアに対してレート制限、金額上限、許可モデルを設定できます。加えて、レイヤ化された構成により下位省庁向けのデフォルトを設定でき、Claude が何に接続できるか、どの機能が利用可能か、そして Claude がユーザーとどのようにやり取りするかを導くインストラクションまでを含めて指定できます。

**設計に組み込まれた監視性。** すべての管理アクションはハッシュチェーンでつながれた監査ログに記録され、組織管理者はプロダクト内で直接確認できます。Anthropic 側での機微な操作には二者による承認が必要です。利用状況のエクスポートは計測データのみを含むため、省庁は機微な情報を動かすことなく ATO や IG からの照会に応えられます。

## セキュリティと監視性

デスクトップ展開を評価するセキュリティチーム向けに、私たちは FedRAMP Secure Configuration Guide を公開ドキュメントとして提供します。お客様はこれを使って Claude for Government プロダクトを安全に構成できます。

加えて、FedRAMP は今回の変更に関する詳細を含む正式な変更通知の提供を私たちに義務付けています。

最後に、新しいデスクトップクライアントのペネトレーションテストサマリーが利用可能で、後続のペネトレーションテストサマリーも用意が整い次第提供されます。変更通知とペネトレーションテストサマリーは、NDA のもと Anthropic の trust center から入手できます。アプリケーションは標準的な省庁の MDM プラットフォームを通じて配布されます。

## 使い始める

Claude for Government は本日よりベータで利用可能です。Anthropic が引き続き契約と課金の当事者となるため、省庁は別途クラウドプロバイダとの関係を持つ必要はありません。

新規のお客様は [claude.com/solutions/government](https://claude.com/solutions/government) からアクセスをリクエストできます。

セキュリティチームは [こちらのリンク](https://trust.anthropic.com/resources?s=gutlu13ft6nd7famxolbxg&name=[anthropic]-2025-annual-penetration-testing-reports) からペネトレーションテストの成果物をダウンロードできます。
