# Claude Duet のご紹介（Introducing Claude Duet）

本日、Claude Duet のリサーチプレビューを開始します。Claude Duet は、Claude がプロアクティブなエージェントとして働く新しいアプリです。あなたが注意を向けるべきことを自ら知らせ、依頼したタスクを完了し、あなたが席を外している間も作業を続け、あなたの代わりに行動する前には必ず確認を取ります。Claude Duet は、把握しきれないほど多くの仕事を抱えるプロフェッショナルや小規模事業者のために作りました。

iOS と Android のスタンドアロンアプリ、および claude.ai で利用できます。今回のリサーチプレビューでは、Claude Duet は Pro、Max、Ultra プランに含まれ、Claude の他の機能と同じ利用上限を共有します。利用するには、[ウェイトリストに登録](https://claude.com/product/claude-duet)してください。

## 最も重要なことに注意を向ける

私たちは Claude Duet を、信頼できるパートナーとなるよう設計しました。あらゆる職種のプロフェッショナルは、日々多くの判断をこなさなければなりません。そうした方々にこそ Claude Duet が最も役立つと考えています。Claude Duet は、時間とエネルギーをどこに注ぐべきかの優先順位づけを助け、これまで不可能に思えたり、尻込みしたりしていた野心的なプロジェクトに取り組む余裕を生み出します。

Claude Duet がこれほど役に立つのは、その判断力のおかげです。私たちは [Claude Opus 5.5](https://www.anthropic.com/claude-opus-5-5) を中心に Claude Duet を設計し、機転を利かせて、何にあなたの対応が必要か、何は後回しにできるか、いつ事前にあなたへ確認すべきかを判断できるように構築しました。

毎朝、接続されたアプリ全体から最も重要な項目をまとめた短いブリーフを送ってくれます。日中はそれらのアプリを見守り、あなたの対応が必要なことがあったときだけメッセージを送ります。また、あらゆる種類のタスクを任せることもできます。会議の日程調整といったシンプルな事務作業から、何十ものツールを使ったダッシュボードの構築、財務予測や売上予測の作成、プロトタイピング、Web アプリの構築といった複雑なものまで対応します。

## 安全性と慎重さを組み込み済み

Claude Duet は、エージェントのセキュリティ、安全性、プライバシーに関する長年の取り組みを基盤としています。これには私たち自身のエージェントに関する取り組みと、企業が自社のエージェントを運用するためのインフラに関する取り組みの両方が含まれます。

- Claude Duet は、私たちの[信頼できるエージェントのためのフレームワーク](https://www.anthropic.com/research/trustworthy-agents)に基づいています。このフレームワークは Claude Code や Claude in Chrome といったエージェントの指針にもなっています。
- Claude Duet の認証情報の扱いは、[Claude Managed Agents](https://www.anthropic.com/engineering/managed-agents) で採用している設計に従っているため、あなたのパスワードやサインイントークンを直接目にすることはありません。
- アクションは [auto mode classifier](https://www.anthropic.com/engineering/claude-code-auto-mode) によって承認されます。これは、Claude や Claude Code があなたの依頼していない手順を実行しないよう守っているのと同じセーフガードです。
- 隠された指示やプロンプトインジェクションに対する Claude Duet の防御は、私たちの[ブラウザ操作に関する研究](https://www.anthropic.com/research/prompt-injection-defenses)に由来しており、私たちのモデルとセーフガードもより広くこれに対処しています。
- Claude Duet のセキュリティインフラに対しては敵対的テストを実施しています。レッドチームと外部企業が Claude Duet のペネトレーションテストを行っており、公開されている[バグバウンティプログラム](https://hackerone.com/anthropic)の対象にもなっています。

**Claude Duet による機密情報の取り扱い。** Claude Duet のリリースにあわせて、各メッセージをチェックして機密情報の漏洩を防ぐ、新たな専用の分類器と安全性システムプロンプトも導入します。あなたの代わりにメールを読み、メッセージを送るエージェントは、情報をどこに送るべきかを常に判断しています。この新しい分類器とプロンプトは、クレジットカード番号や政府発行の身分証明書など、最も厳格な階層の情報の共有リクエストを拒否するよう設計されています。健康や個人の財務状況といったその他の機密情報は、あなたが Claude Duet に送信するよう明示的に指示した場合にのみ送信が許可されます。

私たちはこれらの保護機能の開発と強化を続けており、Claude Duet が安全性のためにどのように設計されているかについて、今後数日のうちにさらに詳しくお伝えする予定です。

## テスターは Claude Duet をどう使っているか

Anthropic の社員は、より多くのことを成し遂げるためだけでなく、考える時間やその場に集中する時間を増やすためにも Claude Duet を使っています。Claude Code チームを率いる Boris Cherny は、頭の中の ToDo リストをデスクに戻るまで取っておくのではなく、散歩しながら Claude Duet と話して整理しています。モデルとプロダクトの振る舞いデザインチームを率いる Chelsea Larsson は、子どもたちと過ごすために退勤する前に ToDo リストを Claude Duet に渡し、その結果を夜のレポートとしてまとめてもらっています。そして Claude Duet の開発チーム自身も、プロダクトの開発に Claude Duet を使っています。チームを率いる Karan Ahuja は、ユーザーインタビューの日程調整、プロトタイプ作りのパートナー、さらにはコードの出荷にまで Claude Duet を活用しています。

私たちは小規模事業者や起業家に Claude Duet への早期アクセスを提供しており、事業運営の助けとして活用している方もいます。その一部の声を紹介します。

## Claude Duet の仕組み

**Claude にあるあなたのコンテキストが土台になります。** Claude Duet は、Claude アカウントのメモリ、スキル、接続済みアプリを引き継ぐため、セットアップにはほとんど手間がかかりません。変わるのは一緒に働く方法です。Claude Duet のほうからあなたに声をかけ、あなたは 1 つの継続的なスレッドの中でテキストまたは音声でメッセージを送れます。そのため、ちょっとした返信も 1 週間がかりのプロジェクトも、同じ場所から始められます。

**席を外しても作業は続きます。** Claude Duet は専用のブラウザを備えた仮想マシンを持っているため、あなたのノート PC やスマートフォンの電源を入れておく必要はありません。短いメッセージでタスクを伝えれば、どのアプリを使い、どの手順を踏むかを判断して、バックグラウンドで作業を進めます。タスクが完了したとき、またはあなたの確認が必要になったときに通知が届きます。

**対応が必要なときにメッセージが届きます。** Claude Duet は数時間ごとに接続済みのアカウントをチェックします。常時チェックし続けると、プランの利用上限をはるかに早く使い切ってしまうためです。いつメッセージを送るべきかという判断については引き続きテストを行っており、テスターからのフィードバックに基づいて調整を続けていきます。どんなことを、どのくらいの頻度で知らせてほしいかを指定することもできます。

**重要な判断はあなたの手に残ります。** Claude Duet は、読む、下書きする、作業を準備するといったことは自律的に行います。しかし、メッセージの送信、支払い、文書への署名、何かの削除を行う前には、これから何をしようとしているのかを正確に示し、あなたの承認を待ちます。有価証券の売買や口座間の資金移動など、あなたの承認があっても実行できないこともあります。また、Claude Duet がアクセスできるアプリはいつでも接続を解除できます。

**ビジネスを支えるツールと連携できます。** Claude Duet は [Claude Marketplace](https://claude.com/marketplace/connectors-plugins) にある 6,000 以上のコネクタとプラグインを使って、次のようなことができます。

- 見逃していた Gmail や Slack のメッセージを見つけ、返信を手伝う。
- Intuit QuickBooks や Stripe で未払いの請求書を確認し、督促の下書きを作成する。
- 勤務時間、ボーナス、経費精算を入力したうえで、Gusto で給与計算を準備・実行する。
- 求人情報の下書きを作成し、あなたが編集・承認したら LinkedIn に投稿する。
- 契約書の作成を手伝い、Docusign を通じてレビューと署名に回す。
- HubSpot の連絡先や商談履歴を使ってフォローアップメールの下書きを作成する。
- 製品のローンチを Canva でソーシャルキャンペーンに仕立てる。
- Shopify ストアの立ち上げ、デザイン、管理を行う。近日中に、より充実したビジュアルエディタが登場し、公開前にストアフロントをデザインしてプレビューできるようになります。

また、Stripe のデジタルウォレットである Link を使って、Claude Duet にビジネス用の買い物をさせることもできます。Claude Duet があなたと商品を確認し、Link が支出の承認をあなたに求めます。その後、バーチャルカードで支払うため、実際のカード番号が共有されることはありません。オンラインストアでのチェックアウトには Shopify の Shop Pay も利用できます。近日中に、あなたの許可があれば、1Password に保存したログイン情報を使ってサイトにサインインできるようになる予定です。

## リサーチプレビューに参加する

これは Claude Duet の初期バージョンであり、スレッドを読み違えたり、緊急度の見極めを誤ったりする可能性があります。中核機能は仕事を中心に構築しているため、チケットの予約といった個人的な用事はまだそれほど得意ではなく、ブラウザの様子をあなたに見せることもまだできません。現時点では、Claude Duet はメインの Claude アプリとは別の独立したアプリとして提供されています。初期ユーザーから得た知見をもとに、両者の連携のあり方を形作っていきます。

リサーチプレビュー期間中、Claude Duet はプランの利用上限を Claude の他の機能と共有しますが、その消費の仕方は通常の会話とは異なります。バックグラウンドでのチェックも上限にカウントされ、財務モデルやスライド資料の作成といった大きなタスクには、より多くのモデルのターンとバックグラウンド処理が必要になります。
