# Anthropic のセールスリーダーが Claude Cowork を使って 4,000 アカウントの担当領域を回している方法

セールスリーダーの仕事は、判断を下すことです。チームの時間をどこに投じるか、四半期の見通しについて経営陣に何を伝えるか。そうした意思決定の周辺にある作業——4 つのシステムからデータをかき集めたり、数値が更新されるたびにベースラインを引き直したり——は、かつては私の週のほとんどを食いつぶしていました。[Claude Cowork](http://claude.com/cowork) が、そのバランスを変えました。データの収集と整形を引き受けてくれるので、私はお客様との会話と戦略的な意思決定に、より多くの時間を割けるようになりました。

私は Anthropic で米国ミッドマーケットの go-to-market を率いており、ミッドマーケットのテックとインダストリーズに分かれた 4,000 アカウントを担当しています。ミッドマーケットには、もうスタートアップではないけれど、大企業にもなりきっていないテック企業が含まれます。インダストリーズは、それ以外のすべて——金融サービス、ヘルスケア、リテール、製造業など——をカバーします。

私の仕事は 3 つのケイデンスにまたがります。日々のお客様コール準備、Anthropic のセールス経営陣への週次フォーキャストロールアップ、そして 4,000 アカウントの全担当領域にわたる四半期ごとのテリトリーとプロスペクトリストの作業です。それぞれ単独でも相当な作業量で、3 つすべてをきちんとこなすのは、以前は不可能でした。

Claude Code も試してみましたが、ターミナルで作業することにどうしても馴染めませんでした。Claude Cowork は同じエンジンを、私が作業できるインターフェイスで包んでくれます。これでようやくしっくりきました。仕事を渡しても、ちゃんとやってくれると信じられる手段が、ついに手に入ったのです。

## **Claude Cowork で私が毎日・毎週・毎四半期に回していること**

Claude Cowork で節約できる時間の大半は、Claude Cowork が私のために回してくれる、約 90 分ぶんの小さな日々の勝ち——マイクロ最適化——から生まれます。

毎朝、スケジュールされたタスクが [skill](https://claude.com/skills) を実行して私の Google Calendar をスキャンし、会議室が押さえられていない外部ミーティングのために会議室を予約します。次の skill は、各ミーティングの前にお客様コールの準備を実行し、BigQuery から消費額を、Salesforce からパイプラインの状況を引いてきて、私がノート PC を開いたときに準備済みのブリーフが待っている状態にしてくれます。skill そのものよりも、スケジューラのほうが大きなブレイクスルーでした。準備が「私が思い出して打つスラッシュコマンド」であることをやめ、勝手に走り出すようになったとたん、私は準備を忘れなくなったのです。

金曜のフォーキャストは次のレベルの作業で、週あたり約 3 時間を節約してくれます。スケジュールされた skill が、Salesforce の Forecast タブから商談レコードと提出済みコミットを、BigQuery からトークン消費額を、いくつかの社内ドキュメントからメモを引いてきます。それらを、Anthropic のセールス経営陣が読みたい形式そのままの 1 ページ Web レポートに組み立てます——トップラインの指標、トップディール、伸びている案件と落ちている案件、各 first-line manager からロールアップされたフォーキャストのスナップショット。skill は月曜のフォーキャストコールの前に、そのページを社内共有リンクへデプロイします。私の月曜の仕事は、コメントを書き足すこと。Claude が「何が起きているか」を組み立て、私は「なぜそうなっているか」を担当します。

Claude Cowork で回した最大のプロジェクトは、ミッドマーケットセグメント全体に対するアカウント傾向スコアリングでした。会計年度ごとに、担当の AE がテリトリーの優先順位を付けやすくするためのスコアを、担当領域内のすべてのアカウントに付ける必要があります。以前の会社や役割では、こういう仕事は RevOps、FP&A、マーケティングにまたがって何百時間も走らせるものでした。それを、私は一晩で終わらせました。

まず、私は Claude と一緒に、2 つの 5 次元スコアリングルーブリックを定義することから始めました。テック向けに 1 つ、インダストリーズ向けに 1 つです。テック側の次元は、エージェント機会、社内トランスフォーメーション、AI へのコミットメント、既存支出に対するホワイトスペース、業界フィットでした。インダストリーズには別のルーブリックを使い、ナレッジワーカー密度（たとえば法律事務所では非常に高くなり得ますし、製造業では多くの従業員が現場にいるため低くなります）や、会社の採用ページ上のメンションで測る公開された AI コミットメントのような次元を持たせました。

ルーブリックが固まったら、Claude Cowork を 4,000 アカウントのリストに向けました。Claude Cowork は一晩走り、各アカウントを 1 件ずつ、深い Web リサーチと Salesforce データ、BigQuery データを使ってスコアリングし、すべての次元について数値スコアと文章での根拠を生成しました。次に、私は Claude Cowork に、その結果からインタラクティブなダッシュボードを作るよう依頼しました。各 AE は自分のテリトリーのパイのスライスをクリックすると、スコア順に並んだ自分のアカウントと、各次元について生成された根拠を見ることができます。アカウントにマウスオーバーすると、想定されるユースケースやプロスペクティングのための類似ケーススタディが表示されます。ダッシュボードのおかげで、スコアはデータ作業の成果物から、実際に使えるセールスツールへと変わりました。

プロンプトはどれも技術的なものではありませんでした。パターンはこうです——スコア付けの対象とする次元を Claude に伝え、テスト用のテリトリーで走らせ、アウトプットを確認し、重み付けを調整し（「D4 はおそらく少し重く付けすぎだと思う。もう少し下げて」）、次のテリトリーを走らせる。

## **なぜ Claude Cowork が私に合っているのか**

Claude Cowork が私に定着した理由は、そのインターフェイスにあります。プロンプトは英文として読め、アウトプットは私がすでに使っている形式（ドキュメント、Web ページ、Salesforce の更新）に落ちてきて、Claude が提案して私が承認するまで何も出荷されないという human-in-the-loop のパターンが組み込まれています。

セールスには、お客様との会話のためにこの仕事を選んだ人がたくさんいます。Claude Cowork は、その会話に充てる時間を彼らに返してくれます。

## **セールスチームはどこから始めるべきか**

私自身の 1 週間から、セールスチームに持ち帰るに値する 2 つのパターンを挙げます。

1 つ目は、準備をスケジュールに乗せること。スケジュールされたタスクは自分自身で走ります。私は、まとめると相当な時間を食ってしまう小さな日々のタスクを思い出す必要がありません。チームに必要な形式を skill に埋め込んでおくことも効きます——私のフォーキャストは、経営陣が読む正確なレイアウトに着地するので、月曜の時間はフォーマット作業ではなくコメントに使えます。自分のセットアップの出発点が欲しい方は、Anthropic の [Sales プラグイン](https://claude.com/plugins/sales) に、コール準備のものを含むベースラインの skill が同梱されています。これらは、あなたのチームが実際にどう働いているかに合わせてカスタマイズすることを前提に作られています。

2 つ目は、大きな戦略プロジェクトを Claude Cowork の一晩ルーチンとして走らせること。4,000 アカウントのスコアリングランは目玉の例ですが、同じ型は TAM サイジング、アカウントリサーチ、競合ベンチマーキングなど、これまで「どのチームにもそんな時間はない」と先送りされてきたあらゆる作業に通用します。必要ならば、翌朝プロンプトを微調整すればよいのです。

Claude Cowork に出会う前は、データの収集、レポートのフォーマット、数値が変わるたびのリベースライニングが私の 1 週間を埋め尽くしていました。今は、戦略的な仕事と、針を動かすお客様との関係づくりの仕事に充てるための時間が、手元に戻ってきました。
